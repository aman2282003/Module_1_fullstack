# Module_1_fullstack

## Overview
This is a full-stack module project for learning Node.js runtime features.

## Features
- Node.js Runtime Features exploration
- Sample data processing
- File handling examples

## Getting Started
1. Navigate to the "Node.js Runtime Features" folder
2. Run `npm install`
3. Execute `node index.js` to start
